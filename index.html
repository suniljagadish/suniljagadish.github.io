OnboardingA three week introductory block, two sessions a week

6 sessions
3 weeks
45–50 min each
RPE 6–7
This block is about learning the movements, not loading them. Every set stops around RPE 6 to 7, roughly three reps in reserve. Loads are deliberately conservative because the point of these three weeks is pattern quality and tissue tolerance. Progression comes after.

Session A is the bilateral day, trap bar and squat. Session B is unilateral and posterior chain.

Loads shown are example starting points for a lifter new to these patterns, not prescriptions. Treat the first week of each session as calibration and adjust from there.

Plate maths assumes pairs of 45, 35, 25, 10, 5 and 2.5 lb plates. Trap bars vary between 45 and 60 lb, so set yours on each session page. Rest timers sound an alarm when they expire, so test it from the button in the top bar and keep the ringer switch off silent.
